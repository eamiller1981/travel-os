# Travel OS — Journey Portal Wireframes

Mobile-first interactive HTML wireframes for the **Travel OS** family portal.

## Navigation (IA v2)

| Tab | Screen | Purpose |
|-----|--------|--------|
| **Check-In** | `Now.html` | Where is she, is she okay, what's new |
| **This Stay** | `City.html` | Active chapter — games, bingo, wishes, guestbook |
| **Posts** | `Posts.html` | Living feed — reactions, comments |
| **Passport** | `Passport.html` | Personal keepsake book |
| **Journey** | `Explore.html` | Hub for itinerary, vault, gallery, constellation, excursions |

## Behind Journey

- `Trip-Itinerary.html` — Map / Timeline / Calendar
- `Destination-Vault.html` — Past chapters + Closing Spreads
- `Photo-Gallery.html` — Thematic albums + Journey Echoes
- `Family-Constellation.html` — Shared sky of interactions
- `Excursions.html` — Places visited

## View locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

Resize to ~390px width (or use phone).
